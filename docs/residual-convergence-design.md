### 0.2 解剖结论（工作包 A 的直接依据，tests/_probe_p2residual.gd）

1. 9/9 卡点态错格主体 = **3-环（三面循环）**，三角形消解口径占比 44-92%
   （n=7 20261011 达 92%），剩余几乎全为 2-环对换；
2. 卡点形态是「中盘卡住」（placed 65-81%，完成面 8/9 为 0），非收尾坎；
3. B2×2 与 B2×U^a×B2 两合成域「3格3面」形态谱计数 0——§3.5「B2×2=三面
   循环」前提证伪，**三面循环单式必须外部收集**；
4. 风险 6（首宏 inc≥-1 放宽）预算内 0/9、无限预算 5/9——链存在但 cap×3
   不可达，单独实施无意义（A 落地后此结论随池变化重评）。

## 1. 工作包 A：中心段三面循环单式（B3）+ 对换单式

### A0 目标与量级

- 目标：5-7 阶中心段降级率从 100% 回落至 3-环+2-环可治域的实测下界；
  预期按环占比折算（44-92% 消解能力 → 全解率显著回升），**不承诺归零**
  （残余归工作包 C 判定）。
- 量级：A1-A4 约半天；A5 条件项 +1-2 小时；A6 回归半天内。

### A1 公式收集（外部，公共域）

| 项 | 口径 |
|---|---|
| 来源 | speedsolving wiki（MediaWiki `api.php?action=parse&prop=wikitext`，**自定义 UA**，EXPERIENCE 环境坑条）「centres 3-cycle / commutators」条目；佐证渠道 speedsolving.com 论坛公共帖（B 族 B1 先例） |
| 许可 | 同 B 族先例：算法序列=操作事实不受版权，自有结构输出+来源登记；**逐字转译仅限公共域页面**，无开放许可页只作存在性参照 |
| 形态判据 | 模拟器读回置换：**moved==3 ∧ 三格分属三面**（=解剖 G2 口径）；keeps ≥ 3 面（三作用面外全保持） |
| 数量预期 | 1-3 个基础式 × 轨道档（§A2），4 阶单轨道起步 |

### A2 转译与轨道展开（N≥5）

- 记号转译：社区 `r/u/d`（宽层）→ 引擎 `2Rw/2Uw/2Dw`；slice `M/E/S` 不用
  （拆宽层复合，B 族 §3.3 转译表先例）；逐 token 过 `is_valid_wca_token`。
- 轨道档：内层深度 d∈{3..n-1}（数字内层自面计数），中央档自消预期保留
  G1 滤（B1 n=5 d=3 先例）；N≥5 展开域 = y4×x2 姿态（8/基础式/档，B 族同款，
  **不加 U^a 前缀**——解剖证明 U 缀对中心格是大动作，摆位由引擎 BFS 承载）。

### A3 四步管线验证（§3.4 同款，逐条过）

1. 语义环断言：复原态布置「三面循环」终态 → 应用宏 → 三面各 1 格循环归位、
   其余中心格逐位复原（模拟器读回比对）；
2. keeps 断言：非作用三面 setwise+逐位保持；
3. 布置终态全解：构造含 3-环错格的态 → 宏 → 该 3-环消解；
4. 对拍：复合/数字两记法形式终态一致（有复合形式时）。

### A4 入池接入

- `b3_specs` 常量数组（带来源注释，B 族同款格式）→ `_cn_ensure` 构建期展开
  → a_pool1（择优域）+ end_atoms（收尾域）；G1 非恒等 + G2 形态登记
  （moved==3 ∧ 3 面）构建期 assert；
- 池膨胀预算：每式 ≤8 条/档 × 1-3 式 × 档数 ≤ n-3 → n=7 上界 64 条，
  与 B 族同量级；探针 P95 单段时长盯 §6 风险 1。

### A5 对换单式（条件项，B3 后采样触发）

- 触发：A6 回归后若残余卡点仍以 2-环对换为主体（复用 _probe_p2residual
  环分解，剩余环 len==2 占比 > 50%）；
- 方向：中心格 2 格对换单式（moved==2，大阶中心格群无奇偶约束，commutator
  可构造）或 B1 细粒度变体；A1-A4 同管线复用，增量 1-2 小时；
- 不触发则关闭（2-环已被 B3 联动消解或 T 族覆盖）。

## 2. 工作包 B：组棱段缺口

### B0 前置重测（A 的后置依赖，小时级）

层 a「全降级」的归因目前混杂：层 a = 全打乱 → 中心段 → 组棱段，5-7 阶
中心段 100% 降级在前，组棱段真实缺口被掩盖。**B0 = A6 完成后重跑 TNE-6
层 a/层 b，拆出纯组棱段降级率**（中心段已解的态里统计组棱段 error 占比），
以此为 B1/B2 的开工基线。B0 结果决定 B 的实际规模，本文档 B1/B2 口径按
当前认知预写、开工前按 B0 修订。

### B1 wing 交叉构型（4 阶主治，P4b 论证条款同款：先论证后收集）

- 现状：EDGE_BASES 池（nxn_solver.gd:1198-1205，r 系破坏+恢复/u,d 系配对/
  A 段最后两棱/PLL parity 双对换）为偶置换复合域，13/30 态卡点 =
  10/12 对交叉构型需 wing 奇置换效果（nxn_solver.gd:1187-1188 熔断记录）。
- **开工前论证（必须）**：探针普查 13 降级态的 wing 置换类型（对目标配对态
  的置换分解）——确认「奇置换效果」的确切形态（单 3-cycle 含翻转？双交叉对换？
  ——v7 记忆口径「10/12 对交叉」需实证细化）；群论约束核对：面转对 wing 的
  置换恒偶（R=两 4-cycle），奇效果宏必含「配对目标视角」的非常规路径——
  论证结论决定收集形态，防盲目收集。
- 收集方向（论证后定）：社区 4 阶「last two edges 交叉 / parity fix」公共
  教程族（ruwix A 段扩展、speedsolving wiki 4x4 edge parity 条目）；
  许可与管线同 A1/A3。
- 接入：EDGE_BASES 追加 + `_edge_local` 复合域自动扩；验收 = TNE-4/5
  DEGRADED-RATIO 收敛（13/30 → 实测下界）+ 段级判据（已配对保持）不破。
- 量级：论证半天 + 收集转译验证 1 天。

### B2 mid 段（5-7 阶，条件项）

- 设计已备：v7-impl-design.md §M0-M6（宽层夹心族 `dRw·core·dRw'`、先
  mid-mid 后 mid-wing、槽位自由度、M6.2 开工前论证验收项）——B0 重测后若
  mid 段降级仍显著才开工，按既有 M 节设计执行，本文档不重复。
- 量级：1-1.5 天（v7 实施期口径）。

## 4. 总体排期与依赖

```
push 8f6eccf（先行,零成本）
  └→ A1-A4 B3 落地（半天）
       └→ A6 验收（半天内）
            ├→ A5 对换单式（条件,+1-2h）
            └→ B0 重测（小时级）
                 ├→ B1 wing 论证+收集（1.5 天）
                 └→ B2 mid（条件,1-1.5 天）
```

- 串行理由：B0 依赖 A6（中心段修复改变层 a 可达性）；C 依赖 A+B 的残余采样；
  A 内部 A1→A4 强串行（管线逐条）。
- 总量级：A ≈1 天 / B ≈2-3 天（含条件项）/ C 不排期；全程 lbl_solver 零改动、
  §2.6 四过滤与既有搜索参数红线不动（B3 是池扩充，不是搜索改动）。

| # | 风险 | 触发信号 | 回退 |
|---|---|---|---|
| 1 | B3 池膨胀性能回涨 | 探针 P95 单段 > 基线 ×1.2 | 轨道档裁剪（远档 d>n-3 撤出 a_pool1 留 end_atoms）；T 族远档裁剪已证伪勿重复 |
