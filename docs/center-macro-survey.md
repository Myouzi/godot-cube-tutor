## 1. 结论摘要(TL;DR)

**5-7 阶中心段 100% 降级的剩余缺口是宏池表达力,不是搜索调参;对应补法是两个宏族——中盘 3-cycle 族(拆团)与收尾两面族(散点驼峰),外加一段「对面等价」度量改造作为后备。**

1. **基线与定调**(EXPERIENCE.md:43、PLAN.md:301):5-7 阶打乱态降级率 100%(40/40),n=4 为 0%;两处真缺陷(奇阶真中心可达性、focus 期度量震荡)已修复入引擎;四路搜索调参实验(guard 300/1600、随机重启 ×10、逃逸搜索 20k 节点 depth-4、end_dfs 预算 19.8k)对 lex 局部最优**全部 0 破解**,已回退瘦身。
2. **卡点实测加细**(§4):solve 层面 9/9 降级均为「超 guard 上限」error 形态(细分:7 例 guard 段限、2 例步限先至,第 11-13 段,错格尚 27-101 个大团);放宽至 250 段/900 步续跑后 9/9 全部四层搜索真穷尽,形态分化三类——散点驼峰(n=5,2 例)、散点+中团混合死坎(n=5/6,4 例)、大团深混沌(n=7,3 例)。**穷尽段 18-55、步 62-226,落在工作包预估区间(guard 100-250 段/400-900 步)内**——宏族量级预估合理。
3. **宏族与卡点的对应**(§6.1):中盘 3-cycle 族(整条带交换 + 8 步中轨骨架,可纯生成入池)主治类 3/4 的团块;收尾两面族(Bader 收尾三件套转译 + 轨道展开,属「收集的」公式,须走完整入池条款)主治类 2 驼峰;「对面等价」度量(dwalton76/Kociemba 宽松归位结构)为后备,针对「五环构型」——该构型在本批样本**未复现**(9 个穷尽态完成面全为空集),故后备段不排期,留触发条件。
4. **必要条件已实证、充分性待验证**:guard 12→250 上调是必要非充分(250 段下 9/9 仍真穷尽,无一预算内解完)——上调必须与宏族同批落地,单上调已证伪。
5. **许可边界一处更正**(§5.2):本项目已是 GPL-3.0(仓库根 LICENSE),上游调研「hkociemba 代码不可并入(MIT 类自有引擎前提)」不成立——GPL→GPL 可并入;但其在线 prune+DFS 结构与教学引擎不同构,实际价值仍在思路层(斜轨成对处理、宽松归位→定向两遍法)。

## 2. 问题陈述

### 2.1 降级现状

4~7 阶降阶法 9 段中第 1 段「拼中心」在 5~7 阶打乱态上 **100% 触发降级熔断**(40/40,n=4 为 0%;EXPERIENCE.md:43、PLAN.md:301)。降级形态:solve 返回 `ok:false`,error 含「(降级)」标记,经 `_nxn_solve`(scripts/nxn_solver.gd:3123-3126,按调研转录)加前缀「中心段: 」透传至 MCP 响应;hint 侧 `_cn_hint` 同口径(tests/test_server.gd:19 的 `S9_DEGRADE_MARK="(降级)"` 即此标记的测试断言)。

### 2.2 已定性根因(两处真缺陷已修,EXPERIENCE.md:44-45)

1. **奇数阶可达性**:打乱含核心层转层时真中心整体搬到别的面(n=5/7 实测 88-93% 偏离原面),『每面=原色』目标不可达——任何搜索调参都救不了。已修 = `_cn_prealg`(scripts/nxn_solver.gd:2250-2284,已实读核实):枚举 24 个核心旋转,模拟命中「真中心各回原面」即作首段(2209-2217 计入 segs)。
2. **focus 期度量震荡**:贪心曾同时接受『placed 增 ∧ 对格降』宏,两度量互相让位无限弹跳(n=6 实测 placed 43↔44 跑满 300 段)。已修 = 对格单调非降 + 对格平台期需 placed 增 + 爬升期允许 placed ≤2 回退(nxn_solver.gd:2006-2014,已实读核实)+ 逃逸 BFS placed 有底 p0-3。

### 2.3 剩余缺口定调(四路调参证伪)

EXPERIENCE.md:46 + PLAN.md:301:guard 上调(300 段/1600 步)、随机重启(×10)、逃逸搜索加宽(20k 节点 depth-4)、end_dfs 加预算(19.8k)四路实验对『差 1-2 格收尾坎 / 1 面完成后 5 环构型』的 lex 局部 optimum **全部 0 破解**,且推高失败路径成本(test_nxn_edges 21s→84.6s),已全部回退(失败路径 7-13ms/态)。定稿结论:**剩余缺口 = 宏族扩充(中盘 3-cycle 宏 + 收尾两面宏),非搜索调参**。

> 记载不一致(如实呈现):第 4 路实验在 EXPERIENCE.md:46 / PLAN.md:301 记为「end_dfs 19.8k 预算」,而代码注释 nxn_solver.gd:2219(已实读核实)写作「time box」。两处口径不一,以 EXPERIENCE/PLAN 的『end_dfs 19.8k 预算』为准;对本结论无影响(四路均 0 破解)。

## 3. 求解器现状盘点(5-7 阶 `_cn_` 路径)

### 3.1 四级链结构

四级链定义在 `_cn_segment`(scripts/nxn_solver.gd:1917-1927,已实读核实):依次试 `_cn_greedy → _cn_bfs → _cn_end_dfs → _cn_bfr`,前级返回非空即用,全空返回 `{}`(上层降级)。

| 级 | 函数 | 机制 | 进入下一级的触发 |
|---|---|---|---|
| 1 | `_cn_greedy`(:1983-2027) | depth-1 单宏贪心:遍历 pool1 全池;keeps 硬约束保完成面;focus 期三段严格单调过滤(ma<0 拒 / ma==0 需 inc>0 / ma>0 允许 inc≥-2,:2009-2014);非 focus 期 inc>0;**first-hit 早退**(:2023) | 全池无宏通过过滤(best 空,:2024) |
| 2 | `_cn_bfs`(:2032-2091) | 卡点约束 BFS:域 = bfs_atoms 过滤 keeps⊇done0;深度 ≤ CN_BFS_DEPTH(2) 宏、节点 ≤ CN_BFS_NODES(3000) 且轮次 < ctx.cap(800);剪枝 = focus 期 maxalign 非降 ∧ placed ≥ p0-3 | 穷尽(队列空/超限) |
| 3 | `_cn_end_dfs`(:1932-1950) | 收尾迭代加深 DFS:域 = end_atoms(小原子+摆位缀);深度 2→3;节点预算 cap×3=2400;剪枝 = placed 不降 + 完成面保持(:1964-1966,已实读核实) | 预算烧尽 |
| 4 | `_cn_bfr`(:2097-2154) | 破坏+恢复:破口域 = conj1(含 D 共轭);破口条件 = 真破完成面/真掉 placed(:2121-2122);须触及错位面且掉幅 ≤4(:2123-2125);至多 4 候选各跑 `_cn_repair`(:2159-2193,路径 ≤6 宏、轮次 < cap/4=200) | 全候选修复失败 |

**失败下传**:`_cn_solve`(:2198-2243,已实读核实)主循环先 `_cn_prealg` 预对齐;每段 guard+=1,guard > CN_STAGE_GUARD(12) 或 total ≥ CN_MOVE_LIMIT(50) → 返回「超 guard 上限(段 %d / 步 %d)」(:2226-2229);`_cn_segment` 返回空 → 返回「卡点态 %s」(:2231-2234)。

**focus 度量**:lex(alignment, placed) —— alignment = `_cn_max_align`(单面最大对格数)、placed = 全部 6(n-2)² 格对格总数;lex 实现为 key2 = ma*1000 + inc(:2020,已实读核实)。注意 `_cn_greedy` 头注释(:1982)写「择 (inc 最大, tokens 最短)」与代码 first-hit 早退不符,**以代码为准**。

### 3.2 宏池清单(`_cn_ensure` :1695-1797,已实读核实)

宏 = 双载体:alg 字符串(引擎记号 token 串)+ perm(中心格整数置换),经 `_cn_id_perm`(:1802-1813,复原态填唯一 id → `_apply_alg` 模拟 → 读回)绑定。池条目 `_cn_entry`(:1818-1835):{alg, perm, keeps, touch, tokens}。

**原子族 bases 四类**(每个 base 经 y4 旋转 × x2 重映射展开 8 姿态,:1724-1731):

| # | 原子族 | 形态 | 层数范围 | 角色 |
|---|---|---|---|---|
| 1 | 宽层 U 夹心交换器 | `dRw {U\|U2\|U'} dRw'` 及撇号变体 | d=2..n-2 | 单块上提/双块交换(4 阶 CENTER_EXCHANGES 的 n 阶推广) |
| 2 | 单内层 U 夹心 | `dR {core} dR'` | d=3..n-2 | 同上,单层 |
| 3 | D 共轭对换器 | `dRw eR' D eR dRw'` | d=2..n-2, e=3..n-1 | **唯一破口材料**(注释 :1704-1706;4 阶 CENTER_CONJUGATE 的 n 阶推广) |
| 4 | 小步长原子 | `dR {3U 3U'\|3U' 3U\|3U2 3U2} dR'` | d=3..n-1 | 收尾期「精确 1-2 格」专用(探针 9:≤6 格效果类唯一来源) |

**派生池**:pool1 = atoms × U^a 前缀 4 档(:1738-1746,贪心主池;无 D 前缀——n=7 全扫 8960 条/段不可负担,:1732-1733 注释);bfs_atoms = pool1 无前缀条目去重 + 9 摆位缀(:1764-1776,BFS/_cn_repair 域);conj1 = pool1 含 " D " 条目(:1778-1781,BFR 破口域);end_atoms = 小原子 + 摆位缀(:1784-1792,收尾域);cap=800(:1796)。

**四类原子共同局限**(卡点实测的反面印证,§4):全部是『相邻轨道三格搬运』——单宏效果域小、无跨面成组重排、无面内重组;这是团块拆不动、孤立错格修复链找不到的宏池层根因。

**遗留死数据(本报告 grep 核实)**:u1 池(:1753-1761 构建,:1794 存入)注释自称「BFS/修复域」,但全文无任何读取方——`grep -n 'u1' scripts/nxn_solver.gd` 命中 5 行(1753 注释 / 1754 var 声明 / 1759、1761 构建 append / 1794 存入 `_cn_ctx`),1794 之外无任何 `ctx.u1` 或 `["u1"]` 读取(BFS/repair 实际用 bfs_atoms)。属遗留未删字段,宏族扩充落地时应顺带清理。
