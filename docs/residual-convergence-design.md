## 0. 背景与目标口径

### 0.1 目标（r1 修订）

**2-7 阶教学管线 solve ok 率 100%**：金标准集 + 大随机采样 0 降级（不触发
「阶段高亮 + 自由练习」熔断兜底）。两条通路分工：

- **主通路（A/B 工作包）**：宏池表达力提升——绝大多数态走短解、教学叙事
  友好（分段 text、阶段演示）。没有它，所有态都走保底长解，功能正确但
  教学体验差。
- **保底通路（D 工作包）**：启发式宏链穷尽时的构造性解法器——数学上不
  穷尽（分解-构造算法），保证任意可达态有解。0% 目标的最终责任者。

### 0.3 解剖结论（A 的直接依据，tests/_probe_p2residual.gd）

1. 9/9 卡点态错格主体 = **3-环（三面循环）**，三角形消解口径占比 44-92%，
   剩余几乎全为 2-环对换；2. 卡点形态是「中盘卡住」（placed 65-81%，完成面

   单独实施无意义（A/D 落地后随池变化重评）。

### A5 对换单式（r1：从条件项升格为必需件）

- 依据：中心格群奇偶自由（内层转给中心格奇置换，4 阶 3U=单 4-cycle 实证），

  **保底器完备性必需**；

  把多余格修回（4-cycle = 对换 × 2 的奇积，拆补后等效单对换），构造性可证。

## 4. 工作包 D：保底解法通道（r1 新增，0% 的构造性保证）

### D0 架构与纪律

- 触发点：各段启发式链穷尽（现有降级 error 出口处）改为转投保底器，
  ok:true 长解返回；保底器自身仅在**步数硬上限**（防对抗态无限展开）触顶
  才降级——上限取工程宽值（CN_FALLBACK_MOVE_LIMIT = 2000），常态打乱态
  不可达（预估最坏 ≈1200 步，见 D1）。
- **宏域解放（设计关键）**：分段顺序 = 中心段 → 组棱段 → 约化 lbl。中心段
  保底器**可动 wing/角**（组棱段与 lbl 会修回）；组棱段保底器**可动 3 阶
  资产**（约化后 lbl 全解）。保底宏域 = 全记号域，构造空间大幅放宽——
  主通路的 keeps/中心保持约束对保底器不适用（只需段末自身目标达成）。
- 教学叙事：保底段 text 统一「保底整理：交换子逐步归位」（阶段标签/演示
  机制不变，长段演示按既有 setup/主体两播放单元口径）。
- 红线不变：lbl_solver 零改动；主通路（greedy/BFS/end_dfs 四级链与四过滤）
  零改动——保底器是**并联**出口，不是修改搜索。

### D1 中心段保底器（1-1.5 天）

- **数学底座**：中心格群奇偶自由 → 任意目标置换 σ = 偶部分 ⊕ 奇部分；
  偶部分分解为 3-cycle 序列（循环分解标准算法，k-循环 → k-1 个 3-cycle）；
  奇部分 = 1 个对换原子（A5 单式或构造回退）。
- **实现路线 1（先行）**：置换分解给出目标三元组 → setup 共轭：在
  「conn 摆位缀 × 姿态 × 短序 BFS」域内把三元组摆到 B3/T 宏作用位 → 宏 →
  undo。setup 域 = 现有 conn 机制扩展，复用度高。
- **实现路线 2（路线 1 覆盖率不足时）**：freestyle commutator 构造器——
  对任意三元组选「过两格的层 A × 过第三格的正交层 B」构造 [A,B] 交换子
  （竞速社区标准手法，效应 ≈ 3-cycle 当 A/B 各含恰一个相关格）；算法化
  层选择 + 效应读回验证。
- 步数预估：每 3-cycle ≤ setup 6×2 + 宏 12 ≈ 24 步；常态打乱残余错格
  10-30 → 240-720 步 + 对换 ≈1 → CN_FALLBACK_MOVE_LIMIT 2000 覆盖。
- 验收：构造性正确性 = 任意随机中心态（含对抗构造的奇置换态）保底器全解
  探针 ≥100 态；保底段末断言 done_mask==63 ∧ 全程中心格外资产无约束。

### D2 组棱段保底（并入 B1/B2 执行，r1 口径）

- 4 阶：B1 公式族覆盖性论证空洞的兜底 = 同 D1 思路（wing 3-cycle/对换
  commutator，宏域含 3 阶资产——角/中心可动，lbl 修回）；仅当 B1 论证
  显示公式族无法覆盖某构型类时实施（预计不需要：L2E 社区清单完备）。
- 5-7 阶 mid：B2 覆盖性论证空洞同上；宽层夹心族设计域预计覆盖（M 节
  实证基础）。

### D3 验收（0% 硬断言，最终门）

| 验 | 口径 |
|---|---|
| ①全解率 | 金标准全集（TNC-6 层 a 各 15 态 + TNE 系 + S9 全 seed + 固定种子 30 态 + 随机扩样 ≥50 态/阶）**ok 率 100% 硬断言** |
| ②断言翻转 | S9 SKIP/哈希锁定分支删除恢复 any_solved；TNE-4/5/6 DEGRADED-RATIO 断言清零；CN_KEY_LOCK 整表删除 |
| ③保底质量 | 主通路/保底通道分界统计（保底触发率实测记档）；保底段播放 E2E 抽样（教学管线长解可播完） |
| ④全量回归 | 17 套件 + py_compile + smoke_bridge；时长预算重估（保底探针耗时计入） |

## 5. 总体排期与依赖（r1）

```
push 8f6ecc9/70e4789（先行,零成本）
  └→ A1-A5 B3+对换落地（约 1 天,A5 必需件含构造回退）
       └→ A6 验收（半天）
            └→ D1 中心保底器（1-1.5 天,路线 1 先行）
                 └→ B0 重测（小时级）
                      ├→ B1 wing 论证+收集+覆盖论证（1.5 天）
                      └→ B2 mid（条件,1-1.5 天）
                           └→ D3 0% 硬断言终验（半天）
                                └→ C 评估（触发率采样,仅教学体验）
```

- 串行理由：D1 依赖 A5（对换原子）与 A4（B3 宏作用位）；B0 依赖 A6/D1
  （中心段修复+保底改变层 a 可达性）；D3 是最终门（B/D2 全落地后）。
- 总量级：A ≈1 天 / D ≈1.5-2 天 / B ≈2-3 天 / 终验 0.5 天 → **约 5-6.5 天**。
- 全程红线：lbl_solver 零改动；主通路四级链与四过滤零改动（D 并联不改）；
  降级兜底 UI（阶段高亮+自由练习）代码保留——作为 CN_FALLBACK 步数触顶的
  最后语义出口（工程宽值下常态不可达）。
