## 1. 工作包 A：中心段三面循环单式（B3）+ 对换单式

### A0 中心群结构论证（r2 新增，全链最前置，A5/D1 共用，半天）

r2 定案（grilling Q1/Q9）：D1 数学底座「任意中心置换可分解」漏了**轨道
结构**——中心格置换必须保持轨道（格位置在 24 旋转群下的等价类；4 阶
x-center 全同轨，5-7 阶每面分多轨道），跨轨道置换物理不可达；且**轨道间
奇偶可能存在耦合**（如 3U 类内层转同时给两个轨道各一个奇置换，比值守恒
类约束可能存在）。本论证产出三项：

1. **轨道枚举**：对 `_cn_cells` 各阶格位做 24 旋转闭包（`_cn_prealg` 的
   旋转置换机制复用），登记轨道表（代码现状无轨道概念，此表为 A5/D1 新底座）；
2. **同轨 3-cycle 可达性实测**：每轨道随机三元组 × B3/T 族作用位构造
   实验（探针），确认轨道内传递性在宏域的落地；
3. **奇偶耦合数值实验**：构造「仅单轨道奇」目标态，群生成器闭包/大采样
   判可达性——产出分支结论：
   - **情形 X（无耦合）**：A5 收集规格 = 单轨 moved==2 单式（每轨道覆盖）；
   - **情形 Y（耦合存在）**：奇原子 = 双轨同步对换复合宏（两轨道各一
     对换，如 3U 类内层转+补偿构造），A5 收集规格相应改写。

排期位置在最前（先于 A1 收集）：收集规格一次定对，防 A5 返工。纯数学+
探针，不依赖任何工作包产出。

**论证产出（2026-10-06 实测，tests/_probe_center_orbits.gd）**：

- 轨道表：n=4 = 1 轨（24 格 x-center 同轨，社区共识吻合）；n=5 = 3 轨
  （角 24 + 边中 24 + 真中心 6）；n=6 = 4 轨 ×24；n=7 = 7 轨（6×24 + 真中心 6）。
- **奇偶耦合两阶分化**：n=4（k=1,r=1）与 n=5（k=3,r=3）= **情形 X**——
  轨道奇偶独立可控，单轨 moved==2 对换单式物理可达；n=6（k=4,r=2，约束
  轨道0⊕轨道3=0 ∧ 轨道1⊕轨道2=0）与 n=7（非真中心 k=6,r=3，约束
  轨道0⊕轨道4=0 ∧ 轨道1⊕轨道3=0 ∧ 轨道2⊕3⊕4⊕5=0）= **情形 Y**——
  单轨对换物理不可达，奇原子须**跨轨双对换复合宏**（moved==4，恰好是社区
  「center swap」公式的常见天然形态，比单对换更好收集）。打乱态的奇偶向量
  自动满足约束（状态由转动生成），保底器按约束配对奇轨道即可。
- 真中心轨道（奇数阶）按不动轨道登记（prealg 已归位，保底宏须保持）。
- 生成元教训：`_cn_axis_tokens` 轴整转是 n-1 层宽转（prealg 专用工具），
  在非真中心格上不等价整体旋转——轨道闭包生成元必须用基本转全体
  （首版碎片轨道 21+1+1+1 即此误）。

## 4. 工作包 D：保底解法通道（r1 新增，0% 的构造性保证）

### D0 架构与纪律

- 触发点：各段启发式链穷尽（现有降级 error 出口处）改为转投保底器，
  ok:true 长解返回；保底器自身仅在**步数硬上限**（防对抗态无限展开）触顶
  才降级——上限取工程宽值（CN_FALLBACK_MOVE_LIMIT = 2000），常态打乱态
  不可达（预估最坏 ≈1200 步，见 D1）。
- **宏域解放（设计关键；r2 措辞收紧）**：分段顺序 = 中心段 → 组棱段 →
  约化 lbl。中心段保底器**可动 wing/角**（组棱段与 lbl 会修回）；组棱段
  保底器**角任意、中心零动**——r2 事实修正：约化提取的中心色取每面 (1,1)
  单格（nxn_solver.gd:3107-3116「中心已解作色参考」），组棱段动中心（哪怕
  面内重排）会使 (1,1) 取色漂移、约化 3 阶态中心色错乱；现池「中心面
  setwise 保持」断言即此约束的池化形态。故保底宏域：中心段 = 全记号域
  （keeps 不适用，只需段末中心全解）；组棱段 = 角任意 + 中心零动 +
  棱（自身目标）。
- **parity 时序纪律（r2 新增）**：保底器不承担 parity，组棱段尾统一判据/
  修正（判据是状态函数，保底器动 wing 后重算天然成立）；中心段无 parity
  概念，不受影响。
- 教学叙事：保底段 text 统一「保底整理：交换子逐步归位」（阶段标签/演示
  机制不变，长段演示按既有 setup/主体两播放单元口径）。
- 红线不变：lbl_solver 零改动；主通路（greedy/BFS/end_dfs 四级链与四过滤）
  零改动——保底器是**并联**出口，不是修改搜索。

### D1 中心段保底器（1-1.5 天）

- **数学底座（r2 补轨道约束）**：中心格置换必须保持轨道（A0 轨道表），
  轨道内任意目标置换 σ = 偶部分 ⊕ 奇部分；偶部分按**轨道内**循环分解为
  3-cycle 序列；奇部分按 A0 耦合结论取对换原子（单轨式或双轨同步复合）。
  轨道内传递性 = 转动群基本性质，setup 搬运表以此为完备基础。
- **实现路线 1（轻量复用）**：置换分解给出目标三元组 → setup 共轭：在
  「conn 摆位缀 × 姿态 × 短序 BFS」域内把三元组摆到 B3/T 宏作用位 → 宏 →
  undo。先验不利（解剖证明 U 缀组合域形态覆盖 0；conn 缀能动侧面中心格
  的范围有限），靠 spike 判定去留。
- **实现路线 2（r2 改写：缓冲法，完备保证）**：盲拧社区标准手法（Old
  Pochmann/3-style 中心版）——固定交换位 P 与缓冲位 Q（同轨道），**预计算
  「任意格位置 → P」的搬运 setup 表**（构建期对位置转移图 BFS 一次；
  setup/undo 框架下 setup 可动任何格，undo 全还原），循环「setup → 固定
  3-cycle 宏（P,Q,作用位）→ undo」直至分解完成。完备性 = 轨道内传递性 +
  setup 表有限预计算。原「freestyle 选层构造器」规格有几何漏洞（分散三
  格常两格不共层），降级为本路线内部宏选择细节。
- **spike 双测与判定预注册（r2，防灰区事后裁量）**：随机**同轨**三元组
  ≥100 组/阶，两路线各测覆盖率与解长（token 数）中位数。判定：路线 1
  覆盖率 <80% → 直接采用缓冲法（不做两路线混合）；80-100% 但解长中位数
  劣于缓冲法 ≥20% → 仍采用缓冲法（解长=教学播放时长，体验优先）；
  其余 → 路线 1。
- 步数预估：每 3-cycle ≤ setup 6×2 + 宏 12 ≈ 24 步；常态打乱残余错格
  10-30 → 240-720 步 + 对换 ≈1 → CN_FALLBACK_MOVE_LIMIT 2000 覆盖。
- 验收：构造性正确性 = 任意随机中心态（含对抗构造的奇置换态、跨轨道
  陷阱态）保底器全解探针 ≥100 态；保底段末断言 done_mask==63；中心格
  外资产（wing/角）无约束（组棱/lbl 修回）。
